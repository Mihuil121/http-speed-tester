# Node.js Sequential Download Speed Benchmark

Консольная утилита на Node.js для последовательного скачивания файла (10 запросов) и точного измерения времени и скорости передачи данных.

## Требования

- **Node.js**: версия 18.0.0 или выше (используются встроенные `globalThis.fetch` и `perf_hooks`).
- Сторонние библиотеки не используются (Zero-dependency).

## Установка и запуск

1. Перейдите в корневую директорию проекта:
   ```bash
   cd nodejs-speed-benchmark
   ```

2. Запустите скрипт через `npm` или `node`, передав желаемый URL аргументом:

   ```bash
   # Через npm (символ '--' передает аргумент в скрипт):
   npm start -- https://raw.githubusercontent.com/nodejs/node/main/README.md

   # Или напрямую через node:
   node index.js https://raw.githubusercontent.com/nodejs/node/main/README.md
   ```

> Если URL не указан, по умолчанию используется дефолтный файл проекта Node.js.

3. Запустите модульные тесты:
   ```bash
   npm test
   ```

## Архитектура проекта

- **`benchmark.js`**: Ядро бизнес-логики. Содержит функцию `runBenchmark`, выполняющую 10 последовательных запросов, замеряющую время и подсчитывающую статистику.
- **`index.js`**: CLI-оболочка. Вызывает ядро `benchmark.js`, обрабатывает параметры командной строки и красиво форматирует результат в консоли.
- **`test/benchmark.test.js`**: Юнит-тесты на основе встроенного тест-раннера Node.js (`node --test`).

## Единицы измерения и формула расчёта

### Единицы измерения:
- **Объём данных**: байты (Bytes), килобайты ($1\text{ КБ} = 1024\text{ байт}$), мегабайты ($1\text{ МБ} = 1024\text{ КБ}$).
- **Время**: миллисекунды (мс), секунды ($1\text{ с} = 1000\text{ мс}$).
- **Скорость**: КБ/с (килобайты в секунду) и МБ/с (мегабайты в секунду).

### Формула расчёта скорости:
Скорость рассчитывается на основе общего суммарного объёма всех успешно скачанных байт и общего реального астрономического времени выполнения (wall-clock time) от старта первого запроса до финиша десятого:

$$\text{Speed (Bytes/s)} = \frac{\text{Total Downloaded Bytes}}{\text{Total Wall-Clock Time (seconds)}}$$

$$\text{Speed (KB/s)} = \frac{\text{Speed (Bytes/s)}}{1024}$$

$$\text{Speed (MB/s)} = \frac{\text{Speed (KB/s)}}{1024}$$

Данный подход учитывает как чистое время передачи байт сервером, так и накладные сетевые расходы (TCP/TLS handshake, RTT) между запросами.
